 Проект посвящён разработке сервиса для автоматического анализа тональности пользовательских отзывов.  
 На вход сервис получает текст отзыва, а на выходе возвращает один из трёх классов тональности: `negative`, `neutral` или `positive`, а также confidence score.  
 Для обучения используются русскоязычные отзывы из открытого датасета RuReviews, а в качестве модели применяется классический NLP-подход: `TF-IDF + Logistic Regression`.

## 2. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта.
- `report.md` – отчёт по проекту: постановка задачи, данные, эксперименты, результаты и описание сервиса.
- `self-checklist.md` – чеклист самопроверки проекта перед сдачей.
- `notebooks/` – экспериментальные ноутбуки:
  - `eda.ipynb` – разведочный анализ данных и подготовка очищенного датасета;
  - `baseline_models.ipynb` – обучение и сравнение baseline-моделей.
- `src/` – основной код проекта:
  - `preprocessing.py` – базовая очистка текста;
  - `config.py` – пути, параметры и конфигурация проекта;
  - `train.py` – обучение финальной модели и сохранение sklearn Pipeline;
  - `predict.py` – загрузка модели и выполнение предсказания;
  - `api.py` – FastAPI-сервис с endpoints `/health` и `/predict`;
  - `batch_analysis.py` – пакетный анализ списка текстов и DataFrame;
  - `streamlit_app.py` – пользовательский Streamlit-интерфейс.
- `data/` – папка для данных:
  - `data/raw/` – исходный датасет, не хранится в GitHub;
  - `data/processed/` – обработанный датасет, не хранится в GitHub.
- `configs/` – конфигурационные файлы:
  - `.env.example` – пример переменных окружения.
- `examples/` – демонстрационные файлы:
  - `demo_reviews.csv` — демонстрационный CSV для проверки пакетного анализа отзывов.
- `tests/` – тесты:
  - `test_predict.py` – проверка функции предсказания;
  - `test_api.py` – проверка API endpoints;
  - `test_batch_analysis.py` – тесты batch-анализа;
  - `conftest.py` – настройка импортов для тестов.
- `artifacts/` – сохранённые артефакты:
  - `sentiment_model.joblib` – обученная модель;
  - `model_metadata.json` – метрики финальной модели.
- `reports/` – результаты анализа и экспериментов:
  - `eda_summary.md`;
  - `metrics.json`;
  - `class_distribution.png`;
  - `review_length_distribution.png`;
  - `confusion_matrix.png`.
- `Dockerfile` – инструкция для сборки Docker-образа.
- `docker-compose.yml` – альтернативный запуск FastAPI-сервиса через Docker Compose.
- `.dockerignore` – исключения для Docker-контекста.

## 4. Как запустить проект

### 4.1. Запуск обучения модели

Для обучения финальной модели используется скрипт:

```bash
python -m src.train
```

Скрипт:

1. загружает подготовленный датасет из `data/processed/reviews_prepared.csv`, если он существует;
2. если processed-файла нет, загружает исходный датасет из `data/raw/`;
3. выполняет базовую очистку текста;
4. обучает модель `TfidfVectorizer + LogisticRegression`;
5. сохраняет модель в `artifacts/sentiment_model.joblib`;
6. сохраняет метаданные и метрики в `artifacts/model_metadata.json`.

Пример результата обучения:

```json
{
    "model": "TfidfVectorizer + LogisticRegression",
    "accuracy": 0.7481,
    "precision_macro": 0.7517,
    "recall_macro": 0.7476,
    "f1_macro": 0.7492,
    "train_size": 68916,
    "test_size": 17230
}
```


### 4.2. Локальный запуск FastAPI-сервиса

```bash
cd project
.venv\Scripts\Activate.ps1
uvicorn src.api:app --reload
```

После запуска сервис доступен по адресу:

```text
http://127.0.0.1:8000
```

Swagger UI доступен по адресу:

```text
http://127.0.0.1:8000/docs
```

### 4.3. Endpoint `/health`
Проверяет, что сервис запущен и модель доступна.

Пример запроса:

```bash
curl http://127.0.0.1:8000/health
```

Пример ответа:

```json
{
  "status": "ok",
  "model_loaded": true
}
```

### 4.4. Endpoint `/predict`

Принимает текст отзыва и возвращает предсказанную тональность.

Пример запроса:

```json
{
  "text": "Качество отличное, товар понравился"
}
```

Пример ответа:

```json
{
  "sentiment": "positive",
  "confidence": 0.971962339335859
}
```

Пример запроса через PowerShell:

```powershell
Invoke-RestMethod `
  -Uri "http://127.0.0.1:8000/predict" `
  -Method Post `
  -ContentType "application/json; charset=utf-8" `
  -Body '{"text": "Качество отличное, товар понравился"}'
```

### 4.5. Запуск Streamlit-интерфейса

Streamlit-интерфейс запускается командой:

```bash
streamlit run src/streamlit_app.py
```

После запуска интерфейс доступен по адресу:

```text
http://localhost:8501
```

В интерфейсе есть два режима:

- **Один отзыв** — ввод текста отзыва, запуск предсказания и вывод `sentiment` и `confidence`.
- **CSV-анализ** — загрузка CSV-файла, выбор текстовой колонки, получение таблицы с полями `text`, `sentiment`, `confidence`, `error`, график распределения классов и скачивание результата в CSV.

Для CSV-анализа можно использовать файл `examples/demo_reviews.csv`.

### 4.6. Запуск через Docker

Docker-запуск предназначен для FastAPI-сервиса. Streamlit-интерфейс запускается отдельно командой `streamlit run src/streamlit_app.py`.

Сборка Docker-образа:

```bash
docker build -t sentiment-review-service .
```

Запуск контейнера:

```bash
docker run --rm -p 8000:8000 sentiment-review-service
```

Альтернативный запуск через Docker Compose:

```bash
docker compose up --build
```

После запуска сервис также доступен по адресу:

```text
http://127.0.0.1:8000/docs
```

## 5. Данные

В проекте используется открытый датасет RuReviews:
```text
women-clothing-accessories.3-class.balanced.csv
```
Источник данных:
```text
https://github.com/sismetanin/rureviews
```
Датасет содержит русскоязычные отзывы о женской одежде и аксессуарах.
Исходная структура данных:

| Колонка | Описание |
|---|---|
| review | текст пользовательского отзыва |
| sentiment | метка тональности |

Исходный размер датасета:
- 90 000 строк;
- 2 колонки.

Исходные классы:

| Класс | Количество |
|---|---:|
| negative | 30000 |
| neautral | 30000 |
| positive | 30000 |

В исходных данных была обнаружена опечатка `neautral`, которая была исправлена на `neutral`.

После очистки и удаления дубликатов подготовленный датасет содержит 86 146 строк.

Распределение классов после очистки:

| Класс | Количество |
|---|---:|
| positive | 28956 |
| negative | 28817 |
| neutral | 28373 |

Файлы данных не хранятся в GitHub, так как они добавлены в `.gitignore`.

Для воспроизведения обучения необходимо вручную скачать файл:

```text
women-clothing-accessories.3-class.balanced.csv
```

и положить его в папку:

```text
project/data/raw/
```

Итоговый путь должен быть:

```text
project/data/raw/women-clothing-accessories.3-class.balanced.csv
```

## 8. Ограничения и дальнейшая работа

Текущие ограничения проекта:

- датасет относится к одной товарной категории: женская одежда и аксессуары;
- модель может хуже работать на отзывах из других предметных областей;
- короткие отзывы могут быть неоднозначными;
- используется классический ML-подход без трансформеров;
- нет авторизации и хранения истории запросов.

Возможные направления развития:

- добавить определение темы отзыва: доставка, качество, цена, сервис, другое;
- добавить авторизацию;
- добавить хранение истории запросов;
- добавить полноценный мониторинг;
- сравнить Logistic Regression с transformer-моделями;
- добавить docker-compose для запуска одной командой;
- расширить датасет отзывами из других доменов.
