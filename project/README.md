## 1. Паспорт проекта

- **Название проекта:** `ML-сервис для автоматической классификации тональности пользовательских отзывов`
- **Автор:** `Данишкин Антон`
- **Группа:** `<Группа ИКБО-09-22>`
- **Контакт:** `<@Deadoxid или danishkin95@mail.ru>`

- **Краткое описание (2-4 предложения):**  
 Проект посвящён разработке сервиса для автоматического анализа тональности пользовательских отзывов.  
 На вход сервис получает текст отзыва, а на выходе возвращает один из трёх классов тональности: `negative`, `neutral` или `positive`, а также confidence score.  
 Для обучения используются русскоязычные отзывы из открытого датасета RuReviews, а в качестве модели применяется классический NLP-подход: `TF-IDF + Logistic Regression`.

## 2. Структура проекта

Проект организован в следующей структуре:

## 4. Как запустить проект

### 4.1. Запуск обучения модели

Для обучения финальной модели используется скрипт:

```bash
python -m src.train
```

Скрипт:

1. загружает подготовленный датасет из `data/processed/reviews_prepared.csv`, если он существует;
2. если processed-файла нет, загружает исходный датасет из `data/raw/`;
3. выполняет базовую очистку текста;
4. обучает модель `TfidfVectorizer + LogisticRegression`;
5. сохраняет модель в `artifacts/sentiment_model.joblib`;
6. сохраняет метаданные и метрики в `artifacts/model_metadata.json`.

Пример результата обучения:

```json
{
    "model": "TfidfVectorizer + LogisticRegression",
    "accuracy": 0.7481,
    "precision_macro": 0.7517,
    "recall_macro": 0.7476,
    "f1_macro": 0.7492,
    "train_size": 68916,
    "test_size": 17230
}
```


### 4.2. Локальный запуск FastAPI-сервиса

```bash
cd project
.venv\Scripts\Activate.ps1
uvicorn src.api:app --reload
```

После запуска сервис доступен по адресу:

```text
http://127.0.0.1:8000
```

Swagger UI доступен по адресу:

```text
http://127.0.0.1:8000/docs
```

### 4.3. Endpoint `/health`
Проверяет, что сервис запущен и модель доступна.

Пример запроса:

```bash
curl http://127.0.0.1:8000/health
```

Пример ответа:

```json
{
  "status": "ok",
  "model_loaded": true
}
```

### 4.4. Endpoint `/predict`

Принимает текст отзыва и возвращает предсказанную тональность.

Пример запроса:

```json
{
  "text": "Качество отличное, товар понравился"
}
```

Пример ответа:

```json
{
  "sentiment": "positive",
  "confidence": 0.971962339335859
}
```

Пример запроса через PowerShell:

```powershell
Invoke-RestMethod `
  -Uri "http://127.0.0.1:8000/predict" `
  -Method Post `
  -ContentType "application/json; charset=utf-8" `
  -Body '{"text": "Качество отличное, товар понравился"}'
```

### 4.5. Запуск через Docker

Сборка Docker-образа:

```bash
docker build -t sentiment-review-service .
```

Запуск контейнера:

```bash
docker run --rm -p 8000:8000 sentiment-review-service
```

После запуска сервис также доступен по адресу:

```text
http://127.0.0.1:8000/docs
```

## 5. Данные


Исходный размер датасета:

Исходные классы:

В исходных данных была обнаружена опечатка `neautral`, которая была исправлена на `neutral`.

После очистки и удаления дубликатов подготовленный датасет содержит 86 146 строк.

Распределение классов после очистки:

## 8. Ограничения и дальнейшая работа

Текущие ограничения проекта:

- датасет относится к одной товарной категории: женская одежда и аксессуары;
- модель может хуже работать на отзывах из других предметных областей;
- короткие отзывы могут быть неоднозначными;
- используется классический ML-подход без трансформеров;
- нет полноценного пользовательского интерфейса;
- нет авторизации и хранения истории запросов.

Возможные направления развития:

- добавить определение темы отзыва: доставка, качество, цена, сервис, другое;
- добавить Streamlit-интерфейс или простое desktop-приложение;
- добавить загрузку CSV-файла с отзывами и агрегированную статистику;
- добавить endpoint `/metrics`;
- сравнить Logistic Regression с Linear SVM;
- добавить docker-compose для запуска одной командой;
- расширить датасет отзывами из других доменов.
